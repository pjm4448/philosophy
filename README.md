# Philosophy

A collection of philosophical essays and writings developing **Agnostic Deism**: an epistemically humble, non-revelatory framework that combines an inference of a non-intervening Architect with constructed ethics, anti-anthropocentrism, finite solidarity, and an honest acceptance of mortality.

The framework treats its claims according to their epistemic status. Scientific observations, philosophical inferences, speculative models, interpretive metaphors, and chosen values are kept distinct. It rejects cosmic privilege and revealed moral authority while defending meaning, responsibility, and care as things finite beings can construct together.
